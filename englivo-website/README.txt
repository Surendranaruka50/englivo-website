ENGLIVO WEBSITE STARTER

1. Extract this ZIP.
2. Open the englivo-website folder.
3. Upload the files inside this folder to your GitHub repository (not the ZIP itself).
4. In GitHub, open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.

IMPORTANT: privacy.html, terms.html and support.html contain placeholders. Complete them with accurate real app/publisher/contact details before publishing. Do not publish placeholder legal text as final policy.
